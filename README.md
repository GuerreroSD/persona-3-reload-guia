# Persona 3 Reload — Guía (fan page)

Página de fans de **Persona 3 Reload** con estética inspirada en la interfaz del juego: historia, protagonista, miembros del SEES, Social Links, Tártaro y combate, plan mes a mes y semana a semana, y la banda sonora oficial vía Spotify.

**Ver online:** https://guerrerosd.github.io/persona-3-reload-guia/

## Contenido
- Menú de pausa al estilo P3R (botón MENU o tecla `M`).
- Modo "Hora Oscura".
- Fichas de personajes con buscador y modal.
- Social Links con retrato y fecha de inicio.
- Plan mes a mes y semana a semana.

Proyecto de fans **sin fines comerciales**. *Persona 3 Reload* y todos sus personajes, arte y música son © ATLUS / SEGA.
